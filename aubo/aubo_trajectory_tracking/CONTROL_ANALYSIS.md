# 跟踪误差分析与 PID / 前馈改进

完整的控制器介绍与 TCP、六轴、诊断、对照图逐项说明见 [CONTROLLER_GUIDE.md](CONTROLLER_GUIDE.md)。插图和数值摘要已保存在包内，不再依赖临时目录。

## 结论与边界

上层原本已经有解析速度前馈，增加完整 PID 不是唯一改善方法。本次对同一 AUBO URDF、同一初始姿态附近、109 mm 半径、40 s、`kp=1 / ki=0 / kd=0` 做了四组对照。执行端是 ROS 位置模拟器，实际位置以 100 Hz 向指令位置作 0.7 比例跟随；底层仍运行真实点动逆解、200 Hz 积分、速度/加速度/jerk 平滑与模型碰撞保护。没有运行 Gazebo 动力学，没有连接 SDK 或实机。

以下为本次样本的运行阶段（不含末点收敛）的误差统计，不是对用户现有 Gazebo 或实机的精度承诺，也不是多次重复试验的统计结论：

| 方案 | 峰值 mm | RMS mm |
| --- | ---: | ---: |
| 固定阻尼 0.02，无加速度前馈 | 2.0421 | 1.0178 |
| 自适应阻尼，无加速度前馈 | 2.0744 | 1.0207 |
| 固定阻尼，加速度前馈 0.10 s | 1.1423 | 0.5095 |
| 自适应阻尼，加速度前馈 0.10 s | 1.1181 | 0.4953 |

单独修改阻尼没有改善这条轨迹的 TCP 误差；主要改善来自加速度前馈。自适应阻尼将模型逆解残差 RMS 从约 0.118 mm/s 降至 0.0012 mm/s，但这项残差原本远小于跟踪运动速度。运行中约束缩放为 1，未触发奇异/限位减速。六个关节的指令/实测位置峰值差约为 0.006–0.040 度，模型中未显示大的执行器跟随误差。这些证据指向该测试中主要存在运动链路滞后，而非单纯缺少电机 PID。

当前无法读取之前截图对应的完整关节历史。Gazebo 的接触、约束求解、控制器执行和反馈抖动仍可能产生速度尖峰；需要重新运行并用新增六轴曲线确认。不能从一张 TCP 图反推六个关节的真实历史。

## 控制链路与改动

链路为：曲线解析位置/速度/加速度 → 末端速度控制 → 阻尼逆解 → 奇异/关节限位整体缩放 → 关节速度/加速度/jerk 平滑 → 关节目标位置 → 执行器 → 原始关节反馈。

现有默认关节平滑器的低通系数为 `alpha=J*h/(2*A)`。对 `A=0.6 rad/s², J=8 rad/s³, h=0.005 s`，`alpha≈0.0333`，对应低通部分的时间常数约 0.147 s。限加速度阶段、逆解变化与真实执行器还会影响总滞后，不能将这个值当作实测总延迟。

上层现在支持：

```
v_ff = velocity_reference + tau_ff * acceleration_reference
v_cmd = v_ff + Kp * position_error + integral + Kd * (velocity_reference - measured_velocity_trend)
```

- 速度、加速度来自同一五次时间缩放轨迹的解析导数，起终点为零，不对噪声位置做二次差分。
- 加速度前馈项最多占总速度上限的 10%，前馈合量不超过 80%；P/I/D 总修正最多占 20%，最终仍受总速度上限约束。
- I 项具有限幅、条件抗饱和、停止清零和末点泄放。D 项使用短窗拟合得到的速度误差，避免直接微分原始位置噪声。默认 I、D 均为 0。
- Gazebo 跟踪入口默认 `acceleration_ff_time=0.10 s`，是有界的保守补偿；通用入口/实机 YAML 默认 0，不假定控制柜延迟。面板可修改，修改后重新预览。
- 已知慢执行端的合成回归（增益 0.8、一阶滞后 0.08 s、30 mm 圆/8 s）中，增加 I/D 的一个测试参数组合收敛且限速，但这不构成实际场景下自动启用 I/D 的依据。

底层自适应 DLS 在远离奇异位形时把阻尼从 0.02 平滑降至 0.002，接近原奇异停止阈值时恢复原阻尼。它降低模型逆解速度偏差，保留全部奇异停止、奇异减速、关节 V/A/J、碰撞及制动保护。未显式配置时仅 Gazebo 默认启用；SDK 和历史 ros_control 路径默认保留固定阻尼。可通过底层私有参数 `adaptive_damping=false` 恢复原固定阻尼模式。

实机还存在 SDK 队列超前、实际动力学和反馈延迟。没有电机电流/力矩命令接口与可靠负载模型时，不能把这次速度前馈视为电机力矩前馈或逆动力学补偿。

## 如何利用图判断原因

| 观测 | 首先检查 |
| --- | --- |
| TCP 有误差，六轴指令与实测基本重合 | 轨迹时间对齐、逆解模型残差、平滑相位滞后、TCP/URDF 标定 |
| 请求速度与逆解后速度偏差明显，运行段缩放为 1 | 阻尼偏差、姿态保持耦合 |
| 运行段缩放小于 1 | 奇异性、关节速度/限位/制动余量；优先调整起点、路径或时长 |
| 逆解后速度正常，平滑后的模型速度滞后 | V/A/J 平滑与加速度前馈参数，不直接放宽保护 |
| 指令关节平滑，某一轴实测抖动/滞后 | Gazebo 执行、接触/约束、关节控制器参数或真实硬件跟随 |
| 指令和实测同时振荡 | 上层增益、速度估计噪声、逆解/限幅切换；不应直接提高 D 增益 |

## 六轴图与导出

“跟踪曲线 / 导出” → “六轴关节 / 链路诊断”，包含四页：

1. 六轴指令/实测位置，单位 deg。
2. 六轴指令减实测位置误差，单位 deg，并显示各轴 RMS/峰值。
3. 六轴指令/实测速度，单位 deg/s。
4. 请求、逆解/限速后、平滑后模型速度；最小奇异值、实际阻尼、缩放及模型残差。

在该页点击“保存 PNG”，会导出 `*_positions.png`、`*_errors.png`、`*_velocities.png`、`*_servo.png`。CSV 导出关节数据与独立的 `*_servo.csv`。图中是机械臂关节输出角，不是减速器前电机转子角。

只读记录器使用命名关节匹配，将生成目标按测量时间戳插值，不外推，不用实测值充当目标；目标缺失时跳过并提示，曲线中断。停止后继续接收 2 s 减速尾段。记录和绘图不参与控制命令生成。

`/cartesian_jog/joint_target` 是**生成位置目标**。Gazebo 下通常接近已下发位置指令；SDK 下是供点生成位置，时间戳不是控制柜消费时间，差值包含队列超前，不能直接称为真实电机伺服误差。诊断的逆解/平滑速度也是由模型与生成状态计算的估计，不代替测量。

`/trajectory_tracking/joint_samples` 共 34 项：

```
[运行时间, 生成目标 q[6], 实测 q[6], 目标-实测[6], 目标速度[6], 实测速度[6],
 插值最大时间间隔, 后端编码, 实测速度来源]
```

CSV 单位 rad、rad/s、s；后端编码 0=Gazebo、1=ros_control、2=SDK；速度来源 1=反馈自带速度、0=位置差分。

`/trajectory_tracking/servo_samples` 共 14 项：

```
[运行时间, 请求线速度[3], 逆解/限速后模型线速度[3], 平滑后模型线速度[3],
 最小奇异值, 阻尼, 整体缩放, 后端编码]
```

默认用同样的 `kp=1, ki=0, kd=0` 比较前馈 0 与 0.10 s，确认效果后再小步试验 I/D。控制参数改变后重新搜索/预览；如果速度缩放或反馈异常，先解决对应问题，不用 PID 掩盖。
