## 加载与位置选择

SRDF 由 MoveIt 启动时加载，因此需在任务结束后重新启动当前分拣 launch，使新命名姿态生效；
仅重启 rqt 不会更新 MoveIt 的机器人模型。按原流程先点击“前往观察位”，等待 READY，再开始分拣。

显式选择原观察位：

```bash
roslaunch aubo_sorting eye_to_hand_can_sorting_real.launch observation_named_target:=real_observe
```

相同参数也适用于 `eye_to_hand_yolo_sorting_real.launch`。不传该参数时遵循 `task_config`，
自定义任务 YAML 可以继续指定自己的观察姿态。
