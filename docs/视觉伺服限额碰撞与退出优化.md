# 视觉伺服限额、碰撞与退出优化

日期：2026-11-03。适用 `aubo_ros_control` 当前实现。本轮不连接实机。

## 1. 运动限额与启动校验

视觉伺服公共参数改为与当前 MoveIt 保守配置一致：

| 六轴分组 | 最大关节速度 rad/s | 最大关节加速度 rad/s² | 最大离散 jerk rad/s³ |
| --- | --- | --- | --- |
| 前三轴 | 0.35 | 0.40 | 8 |
| 三个腕轴 | 0.50 | 0.60 | 12 |

初始化时逐项核对 `joint_names` 与 KDL 链顺序，并加载 URDF 和
`robot_description_planning/joint_limits` 校验位置、速度、加速度上限。
配置超过模型限额会在连接 SDK 前拒绝启动；没有配置模型加速度限额的关节，
仍要求伺服自身加速度参数为有限正数。

点动的既有限额和校验不变。没有调整 MAC 水位、SDK 发送预算或诊断看门狗。

## 2. 独立按需 PBVS 的碰撞与制动检查

默认 `collision_check=true`。对新候选点复制生成器状态，预测零输入制动尾段，
在同一 MoveIt 场景快照中检查候选点、末点及相邻采样最大关节增量达到
`collision_resolution=0.002` 的中间点。预测最多覆盖 600 个 5 ms 步长，
未能在该范围内停稳也拒绝候选点。

候选点或尾段碰撞时，锁存保护，改为衔接此前已验证的零目标减速尾段。
使能和复位也要求当前输出及制动尾段无碰撞；故障不能靠新视觉目标自动解除。
禁用请求直接进入零目标减速，不以碰撞检查通过作为禁用的前提。

场景参数与点动一致：

| 参数 | 默认值 | 行为 |
| --- | --- | --- |
| `planning_scene_topic` | `/planning_scene` | 接收场景更新 |
| `initial_scene_service` | 空字符串 | 非空时必须成功获取完整初始场景 |
| `collision_resolution` | 0.002 | 离散碰撞采样的最大关节增量阈值 |

同时监听 `/collision_object`、`/planning_scene_world`，从 `/joint_states`
更新模型中其它关节状态。开启检查要求提供 `robot_description_semantic`。
真实入口已有 SRDF；合成数值测试可显式关闭碰撞检查。

这是已知场景的离散检查，不是连续碰撞检测、全局避障或自动深度建图。
新出现的障碍物不能撤回已进入控制柜的点；外部障碍物需由场景发布端提供。
`hybrid_enabled=true` 和 `on_demand_output=false` 仍使用原有回放/队列路径，
不自动获得这一按需生成器检查。

## 3. 正常退出

独立按需 PBVS 捕获 SIGINT、SIGTERM 后先锁定退出状态，拒绝重新使能，
将速度目标置零，保留回调与供点线程运行。最多等待 3 秒，要求平滑器停稳、
反馈新鲜且各关节与指令位置差不超过 0.005，再留 0.40 秒名义排空余量。
最后停止回调、关闭 SDK。后端故障或未确认停止时返回失败；排空等待后再次检查后端健康。

平滑退出依赖反馈和通信仍然有效。SIGKILL、外部 ROS shutdown 和 SDK 故障
不承诺完成该流程；0.40 秒余量不是控制柜执行完成的硬件确认。
旧队列/hybrid 保留原有保持行为，不能据此宣称其输出具备新路径的 V/A/J 连续保证。

SDK 成员移到控制状态之后声明，使构造过程异常时也先退出生成线程，再销毁其引用的状态。
进程监控改用墙钟，字符编码仅设置 `LC_CTYPE`，保持 ROS 数值解析区域设置。

## 4. 离线验证

新增制动尾段单元测试：候选点仍无碰撞、后续制动尾段进入障碍时必须拒绝，
并确认预测不修改活动生成器。ROS 测试使用生产视觉前端和假 SDK，不登录控制柜。

```bash
rostest aubo_ros_control visual_servo_startup.test
rostest aubo_ros_control visual_servo_real_model.test
rostest aubo_ros_control visual_servo_safety.test
rostest aubo_ros_control visual_servo_stream.test mode:=eye_in_hand \
  send_delay_ms:=60 accept_late:=false exercise_shutdown:=true shutdown_signal:=SIGTERM
rostest aubo_ros_control initial_observation.test
rostest aubo_ros_control hybrid_control.test
```

启动测试覆盖错误关节顺序及超过模型位置、速度、加速度限额的配置。
安全测试覆盖 90 ms 延迟发送、目标反向、对齐、丢失、禁用、反馈中断、
世界碰撞物体触发保护、故障复位与运动中 SIGINT 退出；另测眼在手上 SIGTERM。
逐点按 5 ms 差分核对本次生效的 V/A/J 限额，包括退出减速段。
实际 AUBO URDF/SRDF 和 MoveIt 限额还单独通过位置话题后端验证：从 HOME
反馈初始化、显式使能/禁用、保持输出不漂移及正常退出，全程不连接 SDK。

合成模型只沿 X 运动，不能代替真实机械臂几何、相机标定、现场障碍和 SDK 长尾验证。
实机仍需采集停止与反向的真实反馈，再决定是否降低 50 点名义 MAC 前瞻。
