# AUBO mobile robot package collection

This outer directory groups all ROS packages belonging to the AUBO mobile
manipulator. It intentionally has no `package.xml`, so catkin treats it as a
package collection and continues discovering the packages below it.

Current layout:

```text
aubo_mobile_robot/
├── aubo_mobile_robot/          # robot Xacro, Gazebo, sensors and controllers
├── aubo_mobile_moveit_config/  # MoveIt planning configuration
├── aubo_mobile_navigation/     # mapping, localization and move_base
└── aubo_mobile_control/        # keyboard and navigation/arm coordination
```

Recommended future layout:

```text
aubo_mobile_robot/
├── aubo_mobile_robot/          # core robot model and Gazebo simulation
├── aubo_mobile_moveit_config/  # MoveIt configuration generated by MSA
├── aubo_mobile_navigation/     # mapping, localization and move_base settings
├── aubo_mobile_bringup/        # unified simulation/real-robot launch files
├── aubo_mobile_control/        # whole-body coordination and command routing
└── aubo_mobile_perception/     # hand camera and lidar processing
```

Keep reusable AUBO arm meshes and the original arm-only packages under the
existing top-level `aubo/` collection. The mobile packages should depend on
them instead of copying the mesh files.
