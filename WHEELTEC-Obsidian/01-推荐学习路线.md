# 推荐学习路线

## 第一阶段：底盘闭环

目标：理解机器人为什么能从键盘指令变成实际运动。

1. 学习 [[功能包/wheeltec_robot_rc]] 如何发布 `/cmd_vel`。
2. 精读 [[功能包/turn_on_wheeltec_robot]] 的启动文件和底盘节点。
3. 观察 `/cmd_vel`、`/odom`、`/imu`、`/PowerVoltage`。
4. 检查 `odom_combined → base_footprint → base_link` 的 TF。

## 第二阶段：传感器

目标：独立启动实际使用的雷达和相机，并确认数据质量。

1. 在 `wheeltec_lidar.launch` 中确认 `rplidar_mode`。
2. 在 `wheeltec_camera.launch` 中确认 `camera_mode`。
3. 使用 `rostopic echo /scan`、RViz 和 `rqt_image_view` 验证输出。
4. 只精读自己硬件对应的驱动包。

参见 [[分类/02-传感器与驱动]]。

## 第三阶段：建图

目标：理解 `/scan + /odom + TF → /map`。

从默认 Gmapping 开始，再比较 Hector、Karto 和 Cartographer。入口在 [[功能包/turn_on_wheeltec_robot]] 的 `mapping.launch`。

## 第四阶段：定位导航

目标：理解静态地图、AMCL、代价地图、全局规划和局部规划的协作。

重点顺序：

1. `map_server`
2. `amcl`
3. `costmap_2d`
4. `move_base`
5. `global_planner`
6. `teb_local_planner` 或 `dwa_local_planner`

参见 [[分类/03-建图定位与导航]]。

## 第五阶段：应用功能

先学习代码规模较小、数据流清晰的 [[功能包/simple_follower]]，再按兴趣选择视觉、YOLO、语音、人体交互、多机或机械臂。
