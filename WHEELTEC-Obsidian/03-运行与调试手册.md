# 运行与调试手册

## 常用启动命令

```bash
# 底盘
roslaunch turn_on_wheeltec_robot turn_on_wheeltec_robot.launch

# 键盘控制
roslaunch wheeltec_robot_rc keyboard_teleop.launch

# 2D 建图与导航
roslaunch turn_on_wheeltec_robot mapping.launch
roslaunch turn_on_wheeltec_robot navigation.launch

# 跟随
roslaunch simple_follower line_follower.launch
roslaunch simple_follower laser_follower.launch
roslaunch simple_follower visual_follower.launch
```

完整厂家命令见仓库根目录的 `ROS常用功能命令5.5.txt`。

## 运行一个功能后的固定检查

```bash
rosnode list
rostopic list
rosservice list
rosparam list
rqt_graph
rosrun rqt_tf_tree rqt_tf_tree
```

检查单个节点：

```bash
rosnode info /节点名
rostopic info /话题名
rostopic hz /话题名
rostopic echo /话题名
```

## 核心话题

| 话题 | 常见类型 | 含义 |
|---|---|---|
| `/cmd_vel` | `geometry_msgs/Twist` | 底盘速度指令 |
| `/odom` | `nav_msgs/Odometry` | 轮式里程计 |
| `/imu` | `sensor_msgs/Imu` | IMU 数据 |
| `/scan` | `sensor_msgs/LaserScan` | 二维激光扫描 |
| `/map` | `nav_msgs/OccupancyGrid` | 栅格地图 |
| `/PowerVoltage` | `std_msgs/Float32` | 电池电压 |

## 常见排错顺序

1. 串口/USB 设备是否存在，权限是否正确。
2. `car_mode`、`rplidar_mode`、`camera_mode` 是否匹配硬件。
3. 关键话题是否存在且频率正常。
4. 消息中的 `frame_id` 是否正确。
5. TF 是否连续，时间戳是否同步。
6. 参数文件是否被正确加载。
7. 最后再怀疑算法代码。

> [!warning]
> 这是 ROS1 Melodic 工程，典型运行环境是 Ubuntu 18.04。Windows 下可以阅读本知识库和源码，但通常不能直接运行整套机器人节点。
