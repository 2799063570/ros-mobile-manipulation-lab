# 功能分类导览

建议沿机器人数据流顺序阅读，而不是按照包名字母顺序：

1. [[01-底盘与控制]]：让机器人能够可靠接收速度并产生里程计。
2. [[02-传感器与驱动]]：获得雷达、相机和 IMU 数据。
3. [[03-建图定位与导航]]：从传感器数据生成地图并自主到达目标。
4. [[04-跟随与自主行为]]：根据局部目标或未知空间产生动作。
5. [[05-视觉与深度学习]]：从图像中检测、识别和跟踪目标。
6. [[06-语音与人机交互]]：将语音、姿态和 GUI 输入转换为任务。
7. [[07-仿真可视化与多机]]：在 Gazebo 中验证系统并扩展到多机器人。
8. [[08-机械臂]]：学习多关节规划与移动操作扩展。
9. [[09-基础库与消息包]]：理解消息生成、插件接口和底层依赖。

## 两条推荐路线

移动机器人主线：

`01 → 02 → 03 → 04 → 07`

智能交互扩展：

`02 → 05 → 06 → 04`
