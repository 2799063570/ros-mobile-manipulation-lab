## 学习原则

1. 先运行功能，观察节点、话题和 TF。
2. 再读 `launch`，确认节点组合与参数来源。
3. 然后读 `package.xml` 和 `CMakeLists.txt`。
4. 最后才读 `src`、`scripts` 中的实现。
5. 对第三方算法包先掌握输入输出，不必从第一行源码开始。

## 核心技术主线

- **移动机器人**：`/cmd_vel` → 底盘控制 → `/odom`、`/imu` → TF → `/scan` → SLAM/AMCL → `move_base`。
- **AUBO 机械臂**：机器人建模 → 关节控制 → MoveIt 运动规划 → 视觉定位 → 抓取与分拣。
- **复合机器人**：自主导航 → 底盘到位与互锁 → 目标识别 → 机械臂抓取 → 分类放置。
